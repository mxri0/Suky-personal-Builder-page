# Suky Builder Page

This project was made for the first **"Raise Your Builder Page"** trial on **Pixi by Hack Club**.

I built this project because I wanted to have a little piece of myself on the internet and give people a way to learn more about me and my personality.

I really like the idea of having something you can **build, write, and design**, while letting people discover who you are. Maybe you'll find something you have in common with someone, or even make friends you would have never met otherwise.

I think it's a very human thing to let others know a little about you, what you like, and what makes you *you*.

## The Process

The process of making this little site was fun and pretty easy.

Whenever there was something I didn't know how to implement, or I ran into a problem I didn't know how to solve, I used Google and AI to help me figure it out.

The easiest part was probably adding things I like, like the shows I watch and love for example, **ATLA**.

I recommend everyone to learn **HTML, CSS, and maybe JS** and try making a personal website. It's a really fun way to learn while creating something that represents you.

## AI Usage

I used Visual Studio Copilot's autofill feature for repetitive tasks and for things like punctuation and text corrections.

I also used Claude to ask questions about HTML and CSS elements.

AI was **not used to create the structure or design of the site**. I would say that around **95% of the code was written by me**.
